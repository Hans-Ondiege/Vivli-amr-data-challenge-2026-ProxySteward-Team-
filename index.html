Two accepted formats:
1. Your surveillance .xlsx — sheets named like 2026 DATA, a meropenem row, and specimen blocks headed FROM BLOOD SAMPLES N=…, URINE SPECIMEN N=…, LOWER RESPIRATORY TRACT N=…. The model finds the meropenem resistance + intermediate figures automatically, for every year sheet in the file.

2. Simple CSV — one row per specimen per year:
year,specimen,N,resistant_pct,intermediate_pct
2026,Blood,750,37.0,1.2
Specimen must be Blood, Urine, or Respiratory. Percentages 0–100 (or proportions 0–1). N is the number of isolates tested. CRKP = resistant + intermediate to meropenem.

3. Funding portfolio (.csv or .xlsx) — one row per project, with columns like Amount USD, Project_Type, Funder Name, Sector, Start Year, End Year. Detected automatically whenever an amount column is present.

Does it actually work?

Tested by hiding the latest year

It trains on every year except the most recent, then predicts that year blind — with a 95% prediction band, not just a single number. The honest test of "within the margin of error" is whether the actual lands inside that band. It does.


±2.6 pts

95%
Of 2,000 re-runs on resampled data keep the same top priority — the ranking isn't a fluke of noise.
Simple, uncertainty-aware models were chosen over complex ones because the data is small — and simple models that pass this test beat complex ones that don't.

What this can't do yet

The honest boundary

Stating the limits up front is part of the design. Each has a clear route to fix.


  • No hospital-level mapNo dataset carries facility or county location, so ranking is by infection type and ward tier — not individual hospitals. → fixed by geolocated sentinel-site data (v2)
  • Funding isn't infection-specificThe portfolio is tagged by function, so the funding axis is a national dial, not a per-infection figure. → fixed by site-mapped funding (v2)
  • The browser engine is a faithful copyIt matches the Python model to 3 decimals, but the Python scripts stay the source of truth for anything published. → re-run ams_priority_index.py to confirm
